コメント（Comment）は、ソースコードに残す注釈です。Rustには`//`から行末までの**行コメント**と、`/* */`で囲む**ブロックコメント**の2種類があります。どちらもコンパイラからは空白として扱われるため、プログラムの動作には影響しません[^1]。

これらとは別に、`///`・`//!`で始まる**ドキュメンテーションコメント**があります。こちらは単なる注釈ではなく`doc`属性として扱われ、`cargo doc`を実行するとrustdocがAPIドキュメントのHTMLに変換します[^1][^2]。<!-- TODO: [[attribute]] 作成後にリンク -->

```rust playground
//! このクレート全体の説明（内部ドキュメント）

/// 消費税込みの価格を計算します。（外部ドキュメント: 直後の関数を説明する）
fn with_tax(price: u32) -> u32 {
    price * 110 / 100 // 税率10%を掛ける（行コメント）
}

fn main() {
    /* ブロックコメントは
       複数行をまとめて囲めます */
    println!("税込: {}円", with_tax(1000));
}
```

## コメントの種類

| 記法 | 種類 | 説明する対象 |
| --- | --- | --- |
| `//` | 行コメント | なし（コンパイラが無視） |
| `/* */` | ブロックコメント | なし（コンパイラが無視） |
| `///` | ドキュメンテーションコメント（外部） | 直後の項目 |
| `//!` | ドキュメンテーションコメント（内部） | 自分を囲む項目 |

外部（outer）・内部（inner）という呼び名は、説明したい対象が自分の外にあるか内にあるかに由来します。`///`は直後の[[function]]や[[struct]]を、ファイル先頭に置いた`//!`はその[[module]]や[[crate]]全体を説明します[^1][^2]。

:::message{warning}
外部形式の`///`は項目の前にしか置けません。`let`[[statement]]などに付けると`unused_doc_comments`警告になり、後ろに項目が続かない位置に書くとコンパイルエラーになります（ブロックの末尾ならE0585、ファイルの末尾なら`expected item after doc comment`。Rust 1.93で確認）。単なる覚書は`//`で書きます。
:::

## 補足

:::details[ブロックコメントは入れ子にできる]
C/C++と違い、Rustの`/* */`は入れ子を正しく数えます[^1]。そのため、すでに`/* */`を含むコードをまとめてコメントアウトしても、途中の`*/`で閉じてしまうことがありません。

```rust
/* 外側 /* 内側 */ ここもまだコメント */
```

:::

:::details[ブロック形式と紛らわしい記法]
ドキュメンテーションコメントにはブロック形式もあり、逆に見た目が似ていても通常のコメント扱いになる記法があります[^1]。

| 記法 | 扱い |
| --- | --- |
| `/** */` | ドキュメンテーションコメント（外部）のブロック形式 |
| `/*! */` | ドキュメンテーションコメント（内部）のブロック形式 |
| `////`（スラッシュ4本以上） | 通常のコメント |
| `/***`（アスタリスク3個以上） | 通常のコメント |

ブロック形式も入れ子は正しく数えますが[^1]、対応する`/*`のない`*/`を書くとそこでコメントが終わってしまいます（Rust 1.93で確認）。実際のコードでは`///`・`//!`の行形式が使われます。

なお`////`は通常のコメントなので、区切り線のつもりで書いてもドキュメントには載りません。

```rust
//// スラッシュ4本は通常のコメント
/*** アスタリスク3個も通常のコメント */
```

:::

::::details[ドキュメンテーションコメント内のコード例はテストされる]
ドキュメンテーションコメントの中身はMarkdownとして解釈されます[^1]。中に書いたコードブロックは**ドキュメンテーションテスト**として扱われ、`cargo test`で実際にコンパイル・実行されます[^2][^3]。ただし対象になるのはライブラリターゲットのドキュメンテーションコメントだけで、バイナリクレートに書いた例は実行されません[^4]。例はクレートを外から使うコードとしてコンパイルされるため、次のように[[use-declaration]]で対象を取り込み、公開された項目を呼び出します[^3]。

````rust:src/lib.rs
/// 消費税込みの価格を計算します。
///
/// # Examples
///
/// ```
/// use shop::with_tax;
/// assert_eq!(with_tax(1000), 1100);
/// ```
pub fn with_tax(price: u32) -> u32 {
    price * 110 / 100
}
````

:::message{tip}
ドキュメントに書いた例が古くなるとテストが落ちるため、説明とコードのずれに気づけます[^2]。
:::
