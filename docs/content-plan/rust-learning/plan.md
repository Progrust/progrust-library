# 動かして学ぶRustプログラミング問題集

このサイトの辞書コンテンツの機能とコードブロックをそのまま「Rust Playground」へ持っていける機能を活かして、Rust未経験者でも実際に問題を解きながら学習するスタイルのカリキュラムで読み進める入門向けの内容。
本コンテンツで作成し、基本文法から所有権など大枠ごとに章で分けて順番に作成する。（各章は長くなりすぎないように適宜調整する）

## 各問題の構成

基本は問題1つに対して以下の構成で作成する

- その問題に関連する辞書コンテンツのリンク一覧（例：〇〇と××に関する問題です。）
- 問題文（こちらに辞書リンクを含めてもOK）
- 問題のコードブロック
- アコーディオンで解答例と解説を記載

### 問題の正誤判定方法

おもに以下の方法で正誤判定を行う。ただし、このサイト上では検知できないので最終判断は学習者の目視確認となる。

- `println!`などでコンソール出力
  - 問題文にあらかじめどのような値が出力されるべきかを記載しておく
- `#[test]`でテストコードを用意
  - あらかじめ用意したテストコードに成功するようにコードを修正させる
  - Rust Playgroundでは`main`関数があると`#[test]`が無視されるため注意が必要（テストで判定させる場合はmain関数を書かない）
- コンパイルエラーの解消
  - コンパイルエラーになる状態から、コンパイルが通る状態へとコードを修正させる

## 各問題の粒度と内容

- 初めて出現する内容の問題については、1つの問題に複数の要素を入れ込まずになるべくその要素単体にフォーカスしたシンプルな作りにする（既出の内容については含めてよい）
- 定期的に応用問題として複数の要素を絡めた内容を出題する

## 注意点

- 問題の順番がそのままカリキュラムとなるため、見たことないものが説明もなく突然問題に現れることがないようにする
- 問題文にはなるべく説明を記載せずに、「なぜエラーになるのか、どうすれば動くのか」などを考えさせるような問題にすること（解説の箇所で説明を記載すること）

## マークダウン記法について

- 解答例でのコードブロックでは、変更した箇所を`[!code ++]`や`[!code --]`のdiffシンタックスハイライトの記法を使用して分かりやすく記載すること。
