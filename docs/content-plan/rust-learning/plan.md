# 動かして学ぶRustプログラミング問題集

このサイトの辞書コンテンツの機能とコードブロックをそのまま「Rust Playground」へ持っていける機能を活かして、Rust未経験者でも実際に問題を解きながら学習するスタイルのカリキュラムで読み進める入門向けの内容。
本コンテンツで作成し、基本文法から所有権など大枠ごとに章で分けて順番に作成する。（各章は長くなりすぎないように適宜調整する）

## 各問題の構成

基本は問題1つに対して以下の構成で作成する

- その問題に関連する辞書コンテンツのリンク一覧（例：〇〇と××に関する問題です。）
- 問題文（こちらに辞書リンクを含めてもOK）
- 問題のコードブロック
- アコーディオンで解答例と解説を記載

### 問題の正誤判定方法

おもに以下の方法で正誤判定を行う。ただし、このサイト上では検知できないので最終判断は学習者の目視確認となる。

- `println!`などでコンソール出力
  - 問題文にあらかじめどのような値が出力されるべきかを記載しておく
- `#[test]`でテストコードを用意
  - あらかじめ用意したテストコードに成功するようにコードを修正させる
  - Rust Playgroundでは`main`関数があると`#[test]`が無視されるため注意が必要（テストで判定させる場合はmain関数を書かない）
- コンパイルエラーの解消
  - コンパイルエラーになる状態から、コンパイルが通る状態へとコードを修正させる

## 各問題の粒度と内容

- 初めて出現する内容の問題については、1つの問題に複数の要素を入れ込まずになるべくその要素単体にフォーカスしたシンプルな作りにする（既出の内容については含めてよい）
- 定期的に応用問題として複数の要素を絡めた内容を出題する

## 注意点

- 問題の順番がそのままカリキュラムとなるため、見たことないものが説明もなく突然問題に現れることがないようにする
- 問題文にはなるべく説明を記載せずに、「なぜエラーになるのか、どうすれば動くのか」などを考えさせるような問題にすること（解説の箇所で説明を記載すること）

## 章構成: 基本文法編（`content/dict/rust-language/01-basic/` 対応）

各問題の表記: **タイトル** — 概要（判定方式 / 関連辞書）。
判定方式は「出力確認」「エラー修正」「テスト」の3種（[問題の正誤判定方法](#問題の正誤判定方法)参照）。

### 第1章 コンソール出力と変数（10問）

1. **はじめてのRustプログラム** — `println!`で`Hello, world!`を出力する（出力確認 / コンソール出力・文字列リテラル）
2. **値を埋め込んで出力する** — プレースホルダ`{}`で複数の値を埋め込む（出力確認 / コンソール出力）
3. **変数を宣言する** — `let`で変数を宣言し、値を出力する（出力確認 / 変数）
4. **変数はデフォルトで不変** — 再代入でコンパイルエラーになるコードを修正する（エラー修正 / 変数）
5. **mutで可変にする** — `mut`付きで宣言した変数の値を更新して出力する（出力確認 / 変数）
6. **定数を宣言する** — `const`の宣言を完成させる（型注釈漏れのエラーを修正）（エラー修正 / 定数）
7. **シャドーイング** — 同名の`let`再宣言で値を作り変えて出力する（出力確認 / シャドーイング）
8. **シャドーイングとmutの違い** — 型の変わる再代入エラーをシャドーイングで解消する（エラー修正 / シャドーイング・変数）
9. **文と式** — ブロック式が返す値を`let`で束縛する（出力確認 / 文・式）
10. **応用: 出力を予測する** — 変数・定数・シャドーイングを組み合わせたコードの出力を合わせる（出力確認 / 第1章の総復習）

### 第2章 基本の型と演算（10問）

1. **整数型** — 型注釈付きで整数を宣言する。`i32`/`u32`などの使い分けを紹介（出力確認 / 整数型・プリミティブ型）
2. **整数型の範囲** — `u8`に収まらない値のエラーを適切な型選択で修正する（エラー修正 / 整数型）
3. **浮動小数点型** — `f64`で小数を扱い出力する（出力確認 / 浮動小数点型）
4. **四則演算** — 加減乗除の結果を出力する（出力確認 / 数値演算)
5. **整数の除算と剰余** — 整数同士の`/`は切り捨てになることと`%`を確認する（出力確認 / 数値演算）
6. **異なる型同士は演算できない** — `i32`と`f64`の混在エラーをキャストで修正する（エラー修正 / キャスト・数値演算）
7. **キャストの挙動** — `as`による小数切り捨て・型変換の結果を確認する（出力確認 / キャスト）
8. **論理値型** — 比較演算の結果を`bool`変数に束縛して出力する（出力確認 / 論理値型）
9. **論理演算子** — `&&`/`||`/`!`を組み合わせた条件の結果を合わせる（出力確認 / 論理演算子・論理値型）
10. **文字型** — シングルクォートの`char`を宣言する（ダブルクォートとの混同エラーを修正）（エラー修正 / 文字型）

### 第3章 制御フロー（10問）

1. **if式で分岐する** — 条件に応じてメッセージを出し分ける（出力確認 / if式）
2. **else ifで多分岐** — 3つ以上の分岐を書く（出力確認 / if式）
3. **ifは式** — `let x = if ...`で値を返す。分岐間の型不一致エラーの修正を含む（エラー修正 / if式・式）
4. **loop式とbreak** — 無限ループを`break`で抜ける（出力確認 / loop式）
5. **breakで値を返す** — `break 値`でloop式から値を取り出す（出力確認 / loop式・式）
6. **while式** — 条件付きループでカウントダウンする（出力確認 / while式）
7. **範囲式** — `..`と`..=`の違いを確認する（出力確認 / 範囲式）
8. **for式で範囲を走査する** — `for i in 0..5`で繰り返し出力する（出力確認 / for式・範囲式）
9. **ループラベル** — ネストしたループを外側までまとめて`break`する（出力確認 / ループラベル・loop式）
10. **応用: FizzBuzz** — for式・if式・剰余を組み合わせる（出力確認 / 第3章までの総復習）

### 第4章 関数（8問）

1. **関数を定義する** — `fn`で関数を定義して`main`から呼び出す（出力確認 / 関数）
2. **引数を渡す** — 引数の型注釈漏れのエラーを修正する（エラー修正 / 関数）
3. **戻り値は末尾の式** — 戻り値型と末尾の式で値を返す（出力確認 / 関数・式）
4. **セミコロンの罠** — 末尾の式にセミコロンを付けて文になってしまったエラーを修正する（エラー修正 / 関数・文・式）
5. **return式で早期リターン** — 条件を満たしたら`return`で抜ける（出力確認 / return式・関数）
6. **ユニット型** — 戻り値のない関数の戻り値が`()`であることを確認する（エラー修正 / ユニット型・関数）
7. **テストに合格する関数を書く** — `#[test]`を使った判定方式を導入し、仕様どおりの関数を実装する（テスト / 関数）
8. **応用: 温度変換関数** — 摂氏→華氏の変換関数を実装しテストに合格させる（テスト / 関数・数値演算・キャスト）

### 第5章 タプルと配列・スライス（10問）

1. **タプルを作る** — 異なる型の値をまとめ、`.0`/`.1`でアクセスする（出力確認 / タプル型）
2. **タプルを分解する** — `let (a, b) = ...`パターンで分解する（出力確認 / タプル型・変数）
3. **関数から複数の値を返す** — タプルを戻り値にした関数を実装する（テスト / タプル型・関数）
4. **配列を作る** — 固定長配列の宣言とインデックスアクセス（出力確認 / 配列型）
5. **同じ値で初期化とlen** — `[値; 個数]`記法と`len()`（出力確認 / 配列型）
6. **範囲外アクセス** — インデックスの範囲外エラーを修正する（エラー修正 / 配列型）
7. **for式で配列を走査する** — 要素を順に出力する（出力確認 / 配列型・for式）
8. **配列の要素を書き換える** — `mut`な配列の要素を更新する（出力確認 / 配列型・変数）
9. **スライスで一部を借りる** — `&arr[1..3]`で配列の一部を取り出す（出力確認 / スライス・範囲式）
10. **応用: 合計と最大値** — for式とmut変数で配列を集計する（テスト / 第5章までの総復習）

### 第6章 文字列とベクタ（10問）

1. **文字列リテラルと&str** — 文字列リテラルの型が文字列スライス`&str`であることを確認する（出力確認 / 文字列リテラル・文字列スライス）

5. **文字列スライスを切り出す** — `&s[0..5]`で一部を取り出す（ASCII範囲で出題）（出力確認 / 文字列スライス・スライス）
6. **1文字ずつ処理する** — `chars()`とfor式で文字を走査する（出力確認 / 文字列型・文字型・for式）
7. **ベクタを作る** — `vec!`マクロと`Vec::new`+`push`（出力確認 / ベクタ（Vec））

10. **応用: 成績集計** — ベクタに値を貯めて合計・平均を計算する関数を実装する（テスト / 基本文法編の総復習）
